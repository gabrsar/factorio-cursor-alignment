Version: 0.4.0
Date: 2026-10-01
  Features:
    - Ctrl+Shift+S can fix a tile-snapped reference while building, copying or selecting.
    - Added native graphical client integration tests and a make test-client target.
  Bugfixes:
    - Fixed settings panel crash caused by a reserved GUI element name.
    - Reset defaults also clears temporary mute and active references.
    - Explicit reference activation now works in manual mode and clears temporary mute.
    - References are released when changing tool or surface; disabled guides ignore input.
    - Added contextual guide detection for rail planners and rail ghosts.
  Info:
    - References are fixed, not continuously snapped. Held Shift still lacks a public API.
---------------------------------------------------------------------------------------------------
Version: 0.3.0
Date: 2026-09-30
  Features:
    - Added a per-player configuration panel, opened with Ctrl+Shift+O or the top button.
    - Added RGB, opacity, additive mixing, contextual/manual/always visibility and grid-only options.
    - Added ten UI languages and an industrial grid thumbnail.
  Bugfixes:
    - Hover activation now snaps the key event's cursor position to a tile, including negative coordinates.
  Info:
    - Held Shift and continuous grid snapping for selection/copy tools remain unavailable through the public API.
---------------------------------------------------------------------------------------------------
Version: 0.2.0
Date: 2026-09-30
  Features:
    - Replaced thin lines with translucent one-tile-wide bands.
    - Added snapped build-cursor guides for ordinary entities and even-size correction.
    - Hover guides require Ctrl+Shift+S and disappear when leaving the entity.
