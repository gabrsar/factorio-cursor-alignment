# Icon

`logo.png` is the full-resolution master. `src/thumbnail.png` is its 144 × 144 pixel export for Factorio, downscaled using bicubic interpolation.

The artwork was generated with OpenAI's built-in image generation tool using an author-provided gameplay screenshot as a composition reference. It depicts a top-down conveyor loop on a charcoal tile grid, with translucent cyan and amber alignment bands and marked reference corners. It is not an official Factorio asset.

The previous icon was replaced in version 0.7.1.
